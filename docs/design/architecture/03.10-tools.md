# Tools 系统

> 工具注册、发现、执行与安全防护

## 概述

Tools 系统是 Agent 与外部世界交互的接口，包含三个层次：

1. **Tool Registry**：工具注册与发现
2. **Tool Definition**：工具定义与 Schema
3. **Tool Execution**：工具执行策略

## Tool Registry

### 职责

- **注册**：内置工具注册、动态工具加载
- **发现**：工具查找、Schema 获取
- **管理**：工具生命周期、缓存

### 核心类型

```rust
/// 工具注册表
pub struct ToolRegistry {
    /// 已注册的工具
    tools: HashMap<String, Box<dyn Tool>>,
    /// 缓存的 OpenAI Schema
    schemas: HashMap<String, serde_json::Value>,
}

/// 工具 trait
#[async_trait]
pub trait Tool: Send + Sync {
    /// 工具名称
    fn name(&self) -> &str;
    /// 工具描述
    fn description(&self) -> &str;
    /// 参数 Schema（JSON Schema）
    fn parameters_schema(&self) -> serde_json::Value;
    /// 执行工具
    async fn execute(&self, params: serde_json::Value) -> Result<String, String>;
    /// 超时时间（默认 30s）
    fn timeout(&self) -> Option<Duration> {
        Some(Duration::from_secs(30))
    }
}
```

### 实现

```rust
impl ToolRegistry {
    /// 创建空注册表
    pub fn new() -> Self {
        Self {
            tools: HashMap::new(),
            schemas: HashMap::new(),
        }
    }
    
    /// 注册工具
    pub fn register(&mut self, tool: Box<dyn Tool>) {
        let name = tool.name().to_string();
        let schema = tool.parameters_schema();
        
        self.tools.insert(name.clone(), tool);
        self.schemas.insert(name, schema);
    }
    
    /// 获取工具
    pub fn get(&self, name: &str) -> Option<&Box<dyn Tool>> {
        self.tools.get(name)
    }
    
    /// 获取所有工具的 OpenAI Schema
    /// 
    /// 用于构建 LLM 请求的工具定义
    pub fn list_schemas(&self) -> Vec<serde_json::Value> {
        self.tools
            .values()
            .map(|tool| {
                json!({
                    "type": "function",
                    "function": {
                        "name": tool.name(),
                        "description": tool.description(),
                        "parameters": tool.parameters_schema(),
                    }
                })
            })
            .collect()
    }
    
    /// 列出所有工具名称
    pub fn names(&self) -> Vec<String> {
        self.tools.keys().cloned().collect()
    }
    
    /// 检查工具是否存在
    pub fn contains(&self, name: &str) -> bool {
        self.tools.contains_key(name)
    }
    
    /// 注销工具
    pub fn unregister(&mut self, name: &str) -> Option<Box<dyn Tool>> {
        self.schemas.remove(name);
        self.tools.remove(name)
    }
}
```

## Tool 定义

### 示例：ReadFileTool

```rust
pub struct ReadFileTool;

impl Tool for ReadFileTool {
    fn name(&self) -> &str {
        "read_file"
    }
    
    fn description(&self) -> &str {
        "读取文件内容。支持文本文件，自动检测编码。"
    }
    
    fn parameters_schema(&self) -> serde_json::Value {
        json!({
            "type": "object",
            "properties": {
                "file_path": {
                    "type": "string",
                    "description": "要读取的文件路径（相对或绝对）"
                },
                "offset": {
                    "type": "integer",
                    "description": "起始行号（0-based，可选）",
                    "minimum": 0
                },
                "limit": {
                    "type": "integer",
                    "description": "读取行数（可选）",
                    "minimum": 1,
                    "maximum": 2000
                }
            },
            "required": ["file_path"]
        })
    }
    
    async fn execute(&self, params: serde_json::Value) -> Result<String, String> {
        let file_path = params["file_path"].as_str()
            .ok_or("file_path must be a string")?;
        
        // 安全检查：路径在工作区内
        if !is_within_workspace(file_path) {
            return Err("Path outside workspace".to_string());
        }
        
        // 读取文件
        let content = tokio::fs::read_to_string(file_path)
            .await
            .map_err(|e| e.to_string())?;
        
        // 处理 offset/limit
        let offset = params["offset"].as_u64().unwrap_or(0) as usize;
        let limit = params["limit"].as_u64().unwrap_or(u64::MAX) as usize;
        
        let lines: Vec<&str> = content.lines().collect();
        let start = offset.min(lines.len());
        let end = (offset + limit).min(lines.len());
        
        Ok(lines[start..end].join("\n"))
    }
}
```

### 执行流程

```rust
impl AgentRunner {
    /// 执行工具调用
    async fn execute_tools(
        &self,
        spec: &AgentRunSpec,
        calls: &[ToolCall],
        hook: &mut dyn AgentHook,
    ) -> Vec<ToolResult> {
        match spec.tool_execution_mode {
            ExecutionMode::Sequential => {
                self.execute_sequential(calls, hook).await
            }
            ExecutionMode::Parallel { max_concurrency } => {
                self.execute_parallel(calls, max_concurrency, hook).await
            }
        }
    }
    
    /// 顺序执行
    async fn execute_sequential(
        &self,
        calls: &[ToolCall],
        hook: &mut dyn AgentHook,
    ) -> Vec<ToolResult> {
        let mut results = Vec::new();
        
        for call in calls {
            hook.on_tool_start(&call.name, &call.arguments);
            let result = self.run_tool(call).await;
            hook.on_tool_end(&result);
            results.push(result);
        }
        
        results
    }
    
    /// 并行执行
    async fn execute_parallel(
        &self,
        calls: &[ToolCall],
        max_concurrency: usize,
        hook: &mut dyn AgentHook,
    ) -> Vec<ToolResult> {
        let semaphore = Arc::new(Semaphore::new(max_concurrency));
        
        let futures = calls.iter().map(|call| {
            let permit = semaphore.clone().acquire_owned().await.unwrap();
            let call = call.clone();
            
            async move {
                hook.on_tool_start(&call.name, &call.arguments);
                let result = self.run_tool(&call).await;
                hook.on_tool_end(&result);
                drop(permit);
                result
            }
        });
        
        join_all(futures).await
    }
}
```

### 单工具执行

```rust
impl AgentRunner {
    async fn run_tool(&self, call: &ToolCall) -> ToolResult {
        let start = Instant::now();
        
        // 1. 查找工具
        let tool = match self.tool_registry.get(&call.name) {
            Some(t) => t,
            None => {
                return ToolResult::error(
                    &call.name,
                    &call.id,
                    format!("Tool '{}' not found. Available: {:?}", 
                        call.name, 
                        self.tool_registry.names()
                    ),
                );
            }
        };
        
        // 2. 参数转换与验证
        let params = match self.prepare_params(tool, &call.arguments) {
            Ok(p) => p,
            Err(e) => {
                return ToolResult::error(&call.name, &call.id, e);
            }
        };
        
        // 3. 执行（带超时）
        let timeout = tool.timeout().unwrap_or(Duration::from_secs(30));
        let result = match tokio::time::timeout(timeout, tool.execute(params)).await {
            Ok(Ok(output)) => {
                ToolResult::success(&call.name, &call.id, output, start.elapsed())
            }
            Ok(Err(e)) => {
                ToolResult::error(&call.name, &call.id, 
                    format!("{}: Please fix and retry.", e))
            }
            Err(_) => {
                ToolResult::error(&call.name, &call.id, 
                    format!("Timeout after {:?}. Please try again.", timeout))
            }
        };
        
        result
    }
    
    /// 参数准备：转换 + 验证
    fn prepare_params(
        &self,
        tool: &Box<dyn Tool>,
        arguments: &serde_json::Value,
    ) -> Result<serde_json::Value, String> {
        // 类型转换（宽容模式）
        let params = cast_params(arguments, &tool.parameters_schema())?;
        
        // Schema 验证
        validate_params(&params, &tool.parameters_schema())?;
        
        Ok(params)
    }
}
```

### 参数处理

```rust
/// 类型转换（宽容模式）
fn cast_params(
    value: &serde_json::Value,
    schema: &serde_json::Value,
) -> Result<serde_json::Value, String> {
    match (value, schema.get("type").and_then(|t| t.as_str())) {
        // 字符串 → 整数
        (Value::String(s), Some("integer")) => {
            s.parse::<i64>()
                .map(Value::Number)
                .map_err(|e| e.to_string())
        }
        // 字符串 → 布尔
        (Value::String(s), Some("boolean")) => {
            match s.to_lowercase().as_str() {
                "true" | "yes" | "1" => Ok(Value::Bool(true)),
                "false" | "no" | "0" => Ok(Value::Bool(false)),
                _ => Err(format!("Cannot convert '{}' to boolean", s)),
            }
        }
        // 数组递归转换
        (Value::Array(arr), Some("array")) => {
            let item_schema = schema.get("items").unwrap_or(&Value::Null);
            let converted: Result<Vec<_>, _> = arr.iter()
                .map(|item| cast_params(item, item_schema))
                .collect();
            converted.map(Value::Array)
        }
        // 其他直接返回
        _ => Ok(value.clone()),
    }
}

/// Schema 验证
fn validate_params(
    value: &serde_json::Value,
    schema: &serde_json::Value,
) -> Result<(), String> {
    let mut errors = Vec::new();
    validate_value(value, schema, &mut errors, "");
    
    if errors.is_empty() {
        Ok(())
    } else {
        Err(errors.join("; "))
    }
}

fn validate_value(
    value: &serde_json::Value,
    schema: &serde_json::Value,
    errors: &mut Vec<String>,
    path: &str,
) {
    // 类型检查
    if let Some(type_) = schema.get("type").and_then(|t| t.as_str()) {
        let valid = match type_ {
            "string" => value.is_string(),
            "integer" => value.is_i64(),
            "number" => value.is_number(),
            "boolean" => value.is_boolean(),
            "array" => value.is_array(),
            "object" => value.is_object(),
            _ => true,
        };
        if !valid {
            errors.push(format!("{}: expected {}", path, type_));
        }
    }
    
    // required 检查
    if let Some(required) = schema.get("required").and_then(|r| r.as_array()) {
        if let Some(obj) = value.as_object() {
            for req in required {
                if let Some(req_str) = req.as_str() {
                    if !obj.contains_key(req_str) {
                        errors.push(format!("{}: missing required field '{}'", path, req_str));
                    }
                }
            }
        }
    }
    
    // 递归检查 properties
    if let Some(props) = schema.get("properties").and_then(|p| p.as_object()) {
        if let Some(obj) = value.as_object() {
            for (key, val) in obj {
                if let Some(prop_schema) = props.get(key) {
                    validate_value(val, prop_schema, errors, &format!("{}.{}", path, key));
                }
            }
        }
    }
}
```

## 错误处理

```rust
pub struct ToolResult {
    pub name: String,
    pub tool_call_id: String,
    pub content: String,
    pub status: ToolStatus,
    pub duration: Duration,
}

pub enum ToolStatus {
    Success,
    Failed,  // 可恢复错误
    Fatal,   // 严格模式下中止
}

impl ToolResult {
    pub fn success(name: &str, id: &str, content: String, duration: Duration) -> Self {
        Self {
            name: name.to_string(),
            tool_call_id: id.to_string(),
            content,
            status: ToolStatus::Success,
            duration,
        }
    }
    
    pub fn error(name: &str, id: &str, message: String) -> Self {
        Self {
            name: name.to_string(),
            tool_call_id: id.to_string(),
            content: format!("Error: {}", message),
            status: ToolStatus::Failed,
            duration: Duration::ZERO,
        }
    }
    
    pub fn is_error(&self) -> bool {
        matches!(self.status, ToolStatus::Failed | ToolStatus::Fatal)
    }
}
```

## 安全防护

```rust
/// 工作区限制
fn is_within_workspace(path: &str) -> bool {
    let path = Path::new(path).canonicalize().unwrap_or_default();
    let workspace = get_workspace().canonicalize().unwrap_or_default();
    path.starts_with(&workspace)
}

/// SSRF 防护
fn is_internal_url(url: &str) -> bool {
    let parsed = Url::parse(url).ok()?;
    
    // 检查危险协议
    if !matches!(parsed.scheme(), "http" | "https") {
        return true;
    }
    
    // 检查 localhost/私有 IP
    if let Some(host) = parsed.host_str() {
        if host == "localhost" || host.starts_with("127.") {
            return true;
        }
    }
    
    false
}

/// 命令注入防护
fn validate_shell_command(cmd: &str) -> Result<(), String> {
    let dangerous = ["rm -rf /", ":(){ :|:& };:", "> /dev/sda"];
    for pattern in &dangerous {
        if cmd.contains(pattern) {
            return Err(format!("Dangerous command: {}", pattern));
        }
    }
    Ok(())
}
```
