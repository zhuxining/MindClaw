# Daily Notes

→ 架构关联：[08-desktop-frontend.md](../design/arch/08-desktop-frontend.md)  
→ 父文档：[00-overview.md](00-overview.md)

## 背景与目标

**背景**：Daily Note 是用户每日工作的锚点——记录当天的想法、待办和复盘。它是"对话流→日记流"内容循环的起点，也是任务的视觉载体。Vault 中每天对应一个 Markdown 文件，Agent 有授权读写权限。

**目标**：定义用户创建、编辑、导航 Daily Note 的完整行为，以及自动保存机制。

## 功能描述

### US-01 打开今日日记

作为用户，我希望打开应用时自动加载今日的 Daily Note，以便立即开始记录，无需手动查找。

**验收标准**：

Given 用户打开应用，且 Daily Tab 为默认激活 Tab  
When 应用完成初始化  
Then 中央区域显示今日日记编辑器，文件路径为 `{vault}/daily/YYYY-MM-DD.md`

Given 今日日记文件不存在  
When 用户首次查看今日日记  
Then 系统自动创建文件，编辑器显示为空内容，光标位于文件开头

- [ ] 日期格式固定为 `YYYY-MM-DD`（ISO 8601）
- [ ] 日记文件存储路径为 Vault 配置中 `daily/` 目录下

**优先级**：P0

---

### US-02 编辑日记内容

作为用户，我希望在 Daily Note 编辑器中输入 Markdown 格式内容，以便记录有格式的文字。

**验收标准**：

Given 今日日记已加载  
When 用户在编辑器中输入文字  
Then 文字实时显示，支持 Markdown 语法的所见即所得渲染

- [ ] 编辑器支持以下 Markdown 功能：标题（H1-H3）、加粗、斜体、无序列表、有序列表、代码块、引用、链接
- [ ] 编辑器支持工具栏快捷操作（加粗：Cmd+B、斜体：Cmd+I、列表：Cmd+Shift+8）
- [ ] 编辑器不支持表格、脚注等复杂 Markdown 语法（Phase 1 范围内不实现）

**优先级**：P0

---

### US-03 自动保存

作为用户，我希望编辑内容时无需手动保存，系统自动将修改写入文件，以便不丢失任何输入。

**验收标准**：

Given 用户正在编辑日记  
When 用户停止输入超过 1 秒  
Then 系统自动将当前内容写入对应日期的 Markdown 文件

Given 编辑器内容正在保存  
When 保存进行中  
Then 编辑器标题区域显示"保存中"指示符

Given 保存完成  
When 文件写入成功  
Then 指示符切换为"已保存"并在 2 秒后消失

Given 文件写入失败（如磁盘空间不足）  
When 保存操作返回错误  
Then 显示红色"保存失败"提示，不自动重试，用户可手动触发保存（Cmd+S）

- [ ] Cmd+S 手动触发立即保存（忽略防抖延迟）
- [ ] 切换 Tab 或关闭窗口时，若有未保存内容，立即同步保存后再执行切换/关闭

**优先级**：P0

---

### US-04 日期导航

作为用户，我希望查看其他日期的 Daily Note，以便回顾历史记录。

**验收标准**：

Given 用户正在查看某日期的 Daily Note  
When 用户点击日记标题旁的"前一天"箭头  
Then 编辑器切换加载前一天的日记（当前编辑内容自动保存后切换）

Given 用户正在查看某日期的 Daily Note  
When 用户点击"后一天"箭头，且当前日期不是今天  
Then 编辑器切换加载后一天的日记

- [ ] 导航到非今日日期时，标题区域显示所查看的日期（格式：`YYYY-MM-DD`）
- [ ] 今日日期时"后一天"箭头禁用
- [ ] 左侧目录树（Daily Tab 下）中点击某日期可直接跳转到该日期的日记

**优先级**：P1

---

### US-05 任务区块显示

作为用户，我希望在 Daily Note 中看到今日的任务列表，以便在写日记时了解当天的执行情况。

**验收标准**：

Given 用户打开今日 Daily Note  
When 有与今日关联的任务（`due_date` 为今日，或 `status` 为 `in_progress`）  
Then 编辑器顶部显示任务摘要区块（独立于正文，不可编辑）

- [ ] 任务摘要区块显示：任务标题、状态徽章（待办/进行中/已完成）
- [ ] 点击任务标题，右侧面板 Tasks 区块展开该任务详情
- [ ] 任务摘要区块不是 Markdown 正文的一部分，不写入日记文件

**优先级**：P2

## 范围界定

**In Scope**：

- 今日日记自动加载与创建
- Markdown 所见即所得编辑（基础语法）
- 防抖自动保存（1 秒延迟）+ 手动保存（Cmd+S）
- 日期前后导航
- 今日任务摘要显示（Phase 2）

**Out of Scope**：

- 模板功能：日记模板（如每日固定结构）需要模板系统支持，不在本文档范围内
- 日历视图：月历/周历视图选择日期是 Phase 3 功能，目录树中按日期列表已满足 Phase 1 需求
- 多 Vault 支持：当前只支持单一 Vault，多 Vault 切换是独立 Feature
- 附件嵌入：图片/PDF 嵌入到日记中需要附件管理系统，排除
