# 反思回顾、演化路径与经验教训候选

→ 架构关联：[03.10-memory.md](../architecture/03.10-memory.md)、[03.11-review-evolution.md](../architecture/03.11-review-evolution.md)、[03.12-observability.md](../architecture/03.12-observability.md)
→ 父文档：[00-overview.md](00-overview.md)

## 背景与目标

**背景**：Agent 的能力变化不能只停留在会话上下文或不可见记忆中。旁路观察需要通过反思回顾被判断，关键变化需要形成演化记录，稳定经验需要先成为可审核的经验教训候选，再进入共有知识。

**目标**：定义旁路观察、轻量回顾、周期回顾、演化记录、经验教训候选审核和知识沉淀的用户可见流程。

## 功能描述

### US-01 查看回顾队列

作为用户，我希望查看回顾队列，以便集中处理观察候选、记忆更新建议和经验教训候选。

**验收标准**：

Given 系统存在待审阅候选
When 用户打开回顾视图
Then 页面按类型列出观察候选、记忆更新建议、经验教训候选和知识草稿入口

Given 用户点击某条候选
When 详情加载完成
Then 右侧面板显示该候选关联的 Session、Daily、Inbox 或 Vault 来源

- [ ] 观察候选以假设状态显示。
- [ ] 观察候选不能直接写入共有知识。
- [ ] 经验教训候选显示适用场景、规则、反例和来源。
- [ ] Private 来源不出现在回顾队列。

**优先级**：P0

---

### US-02 执行轻量回顾

作为用户，我希望在一次 Agent 协作或当日记录结束后做轻量回顾，以便确认本次产生的观察候选、记忆建议和经验教训候选。

**验收标准**：

Given Agent Session 存在用户纠正、失败、确认或草稿
When 用户点击 Review Session
Then 回顾视图显示观察候选、记忆更新建议、经验教训候选和知识草稿入口

Given Daily 存在新增记录、checklist 变化或 Inbox 整理结果
When 用户点击 Review Today
Then 回顾视图显示当日变化摘要和观察候选

Given 用户确认一条记忆更新建议
When 操作完成
Then 该建议进入 Agent Memory，并生成演化记录

Given 用户拒绝一条观察候选
When 操作完成
Then 该候选标记为已拒绝，并不进入 Agent Memory

**优先级**：P1

---

### US-03 执行周期回顾

作为用户，我希望按周期回顾重复出现的模式，以便把多次案例提炼为经验教训。

**验收标准**：

Given 系统存在多条相似观察、案例或用户修正
When 用户打开周期回顾
Then 页面按主题列出可合并的模式候选

Given 用户选择一个模式候选
When 详情加载完成
Then 页面显示支撑该候选的案例列表和反例列表

Given 用户确认模式候选
When 操作完成
Then 系统生成经验教训候选，并关联支撑案例

- [ ] 周期回顾生成的经验教训候选仍需用户审核。

**优先级**：P2

---

### US-04 生成演化记录

作为用户，我希望看到 Agent 记忆或策略为什么发生变化，以便审计 Agent 演化过程。

**验收标准**：

Given 用户对一条记忆执行确认、修正、删除、降权、生成候选或链接知识操作
When 操作完成
Then 系统生成演化记录，记录变化前内容、变化后内容、触发原因和来源

Given 用户查看演化记录
When 详情加载完成
Then 页面显示关联记忆、关联 Session 或关联知识笔记

Given 演化记录来源缺失
When 用户查看详情
Then 页面显示无来源状态，并禁止生成经验教训候选

- [ ] 演化记录不可直接编辑正文。
- [ ] 用户可为演化记录补充备注。
- [ ] 演化记录可按时间、来源、变化类型筛选。

**优先级**：P0

---

### US-05 审核经验教训候选并沉淀知识

作为用户，我希望审核经验教训候选并把确认后的内容沉淀为共有知识，以便 Agent 和人类后续复用。

**验收标准**：

Given 演化记录、记忆或回顾结果可生成经验教训
When 用户点击 Create Lesson
Then 系统生成经验教训候选，包含适用场景、规则、反例、触发条件和来源记录

Given 经验教训候选已打开
When 用户编辑候选并点击 Confirm
Then 候选状态变为已确认，并显示 Save as Knowledge 入口

Given 已确认经验教训候选
When 用户点击 Save as Knowledge
Then 中央内容区打开 Vault 知识草稿，包含标题、`tags`、`overview`、正文和来源链接

Given 知识草稿保存到 Vault
When 保存完成
Then 原候选和相关演化记录显示已沉淀为共有知识，并链接到对应笔记

- [ ] 保存为知识后，Agent Memory 只保留触发条件、短摘要和知识文档引用。
- [ ] 用户拒绝的经验教训候选不出现在默认回顾队列。

**优先级**：P1

## 范围界定

**In Scope**：

- 回顾队列与旁路观察候选审阅入口。
- Session 回顾与 Daily 回顾。
- 周期回顾的模式候选展示。
- 演化记录生成、查看、筛选、备注。
- 经验教训候选审核与共有知识草稿生成。

**Out of Scope**：

- 全自动写入共有知识：共有知识需要用户确认，避免错误经验扩散。
- 对 Private 内容做观察和回顾：该行为违反 Private 隔离边界。
- 将经验教训正文写入 Agent Memory：Agent Memory 只保留调用索引和知识引用。
- 复杂评分体系：MVP 只展示置信状态，不引入多维分数维护。
- 团队协作审批流：当前产品定位为个人桌面工作站。

## 非功能需求

- 回顾视图首屏在 1 秒内显示。
- 单条演化记录详情在 500ms 内显示。
- 生成知识草稿后，草稿 Tab 在 300ms 内激活。
