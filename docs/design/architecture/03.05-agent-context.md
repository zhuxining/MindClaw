# Context Building — 三层上下文架构

> 核心稳定层 / 动态上下文层 / 用户消息层

## 核心命题

> **记忆是 Agent 的，知识是共同的。**

| 维度 | Memory (Agent 私有) | Knowledge (人机共有) |
|------|---------------------|----------------------|
| **存储** | SQLite | Markdown (vault/knowledge/) |
| **操作者** | Agent 自动读写 | 人类直接编辑，Agent 辅助 |
| **内容** | 观察、偏好、模式 | 结构化知识、经验总结 |
| **升华** | 高 importance 记忆 → 知识草稿 → 人类确认 | 直接编辑 |
| **召回** | 自动 relevance + importance 排序 | RAG 检索 |

## 三层架构概览

```
┌─────────────────────────────────────────────────────────────────┐
│ 第 1 层：核心稳定（缓存稳定）                                    │
│ ─────────────────────────────────────                           │
│ SOUL.md / USER.md / AGENTS.md / 核心工具 Schema                  │
│                                                                 │
│ 特点：多次请求间字节级一致，支持 KV-cache 复用                   │
│ 更新：仅当引导文件修改时更新                                     │
├─────────────────────────────────────────────────────────────────┤
│ 第 2 层：动态上下文（每次请求变化）                              │
│ ─────────────────────────────────────                           │
│ Identity（角色选择）/ Memory（Agent 私有）/                       │
│ Knowledge（人机共有）/ Skills（动态加载）                        │
│                                                                 │
│ 特点：每次请求动态组装，无法缓存                                 │
│ 注入：作为独立消息（role: system）插入到历史之前                 │
├─────────────────────────────────────────────────────────────────┤
│ 第 3 层：用户消息                                                │
│ ─────────────────────────────────────                           │
│ 运行时上下文（时间/平台）+ 用户输入 + 媒体                       │
│                                                                 │
│ 特点：每次请求唯一                                               │
└─────────────────────────────────────────────────────────────────┘
```

## 三层 Context Source

```rust
pub enum ContextLayer {
    Core,       // 第 1 层：缓存稳定
    Dynamic,    // 第 2 层：每次请求变化
    User,       // 第 3 层：用户消息
}

#[async_trait]
pub trait ContextSource: Send + Sync {
    fn layer(&self) -> ContextLayer;
    fn priority(&self) -> i32;
    async fn inject(&self, ctx: &BuildContext) -> Vec<Message>;
}

/// 构建上下文
pub struct BuildContext {
    pub session: &Session,
    pub inbound: &InboundMessage,
    pub history: Vec<Message>,
}
```

## 第 1 层：核心稳定

### 组成

| Source | 文件 | 内容 | 优先级 |
|--------|------|------|--------|
| `SoulSource` | SOUL.md | 核心人格、价值观、行为准则 | 0 |
| `UserSource` | USER.md | 用户画像、偏好设置 | 1 |
| `AgentsSource` | AGENTS.md | Agent 定义、能力描述 | 2 |
| `ToolSchemaSource` | - | 核心工具 JSON Schema | 3 |

### 实现

```rust
pub struct CoreLayerBuilder {
    soul: String,        // SOUL.md 内容
    user: String,        // USER.md 内容
    agents: String,      // AGENTS.md 内容
    tool_schema: String, // 核心工具 Schema
}

impl CoreLayerBuilder {
    /// 构建核心稳定消息
    /// 仅在引导文件修改时重建
    pub fn build(&self) -> Message {
        Message::system(format!(
            "{soul}\n\n{user}\n\n{agents}\n\n{tools}",
            soul = self.soul,
            user = self.user,
            agents = self.agents,
            tools = self.tool_schema
        ))
    }
    
    /// 计算内容哈希，用于缓存失效检测
    pub fn hash(&self) -> String {
        use sha2::{Sha256, Digest};
        let mut hasher = Sha256::new();
        hasher.update(&self.soul);
        hasher.update(&self.user);
        hasher.update(&self.agents);
        hasher.update(&self.tool_schema);
        format!("{:x}", hasher.finalize())
    }
}
```

### 缓存策略

```rust
pub struct CoreLayerCache {
    message: Option<Message>,
    hash: String,
}

impl CoreLayerCache {
    pub fn get_or_build(&mut self, builder: &CoreLayerBuilder) -> Message {
        let new_hash = builder.hash();
        if self.hash != new_hash {
            self.message = Some(builder.build());
            self.hash = new_hash;
        }
        self.message.clone().unwrap()
    }
}
```

**设计理由**：

- 引导文件修改频率低，缓存命中率高
- 字节级一致，支持 LLM Provider 的 KV-cache 复用
- 减少 Token 计算开销

## 第 2 层：动态上下文

### 组成

| Source | 职责 | 优先级 | 核心命题对应 |
|--------|------|--------|--------------|
| `IdentitySource` | 角色选择 | 10 | - |
| `MemorySource` | 召回记忆 | 20 | ✅ Agent 私有 |
| `KnowledgeSource` | RAG 检索知识 | 30 | ✅ 人机共有 |
| `SkillsSource` | 动态技能加载 | 40 | - |

### IdentitySource

```rust
pub struct IdentitySource {
    identities: Vec<Identity>,
}

impl ContextSource for IdentitySource {
    fn layer(&self) -> ContextLayer { ContextLayer::Dynamic }
    fn priority(&self) -> i32 { 10 }
    
    async fn inject(&self, ctx: &BuildContext) -> Vec<Message> {
        // 根据用户消息选择最合适的身份
        let identity = self.select_identity(&ctx.inbound.content).await;
        
        vec![Message::system(format!(
            "## 当前角色\n{}",
            identity.description
        ))]
    }
    
    async fn select_identity(&self, content: &str) -> &Identity {
        // 简单实现：关键词匹配
        // 复杂实现：LLM 推理选择
        for identity in &self.identities {
            if identity.keywords.iter().any(|kw| content.contains(kw)) {
                return identity;
            }
        }
        &self.identities[0] // 默认身份
    }
}
```

### MemorySource（Agent 私有）

```rust
pub struct MemorySource {
    memory_store: Arc<MemoryStore>,
}

impl ContextSource for MemorySource {
    fn layer(&self) -> ContextLayer { ContextLayer::Dynamic }
    fn priority(&self) -> i32 { 20 }
    
    async fn inject(&self, ctx: &BuildContext) -> Vec<Message> {
        // 召回相关记忆
        let memories = self.memory_store
            .recall(&ctx.inbound.content, 5)
            .await;
        
        if memories.is_empty() {
            return vec![];
        }
        
        let content = memories.iter()
            .map(|m| format!("- [{}] {}", m.category, m.content))
            .collect::<Vec<_>>()
            .join("\n");
        
        vec![Message::system(format!(
            "## 相关记忆（仅 Agent 可见）\n{}",
            content
        ))]
    }
}
```

**核心命题体现**：

- 记忆存储在 SQLite 中，Agent 自动读写
- 用户不直接操作，只通过对话间接影响
- 高 importance 记忆可升华为知识（需人类确认）

### KnowledgeSource（人机共有）

```rust
pub struct KnowledgeSource {
    db: Arc<DbState>, // 用于 RAG 检索
}

impl ContextSource for KnowledgeSource {
    fn layer(&self) -> ContextLayer { ContextLayer::Dynamic }
    fn priority(&self) -> i32 { 30 }
    
    async fn inject(&self, ctx: &BuildContext) -> Vec<Message> {
        // RAG 检索知识片段
        let knowledge = self.db
            .search_knowledge(&ctx.inbound.content, 5)
            .await;
        
        if knowledge.is_empty() {
            return vec![];
        }
        
        let content = knowledge.iter()
            .map(|k| format!("- {}（来源：{}）", k.content, k.source_path))
            .collect::<Vec<_>>()
            .join("\n");
        
        vec![Message::system(format!(
            "## 相关知识（人机共有）\n{}",
            content
        ))]
    }
}
```

**核心命题体现**：

- 知识存储在 Markdown 文件中，人类可直接编辑
- Agent 通过 RAG 检索使用，不独占
- 记忆升华的知识草稿需人类确认才能成为正式知识

### SkillsSource（借鉴 VikingBot frontmatter）

```rust
pub struct SkillsSource {
    skills_dir: PathBuf,
}

/// 技能清单（frontmatter 解析）
pub struct SkillManifest {
    pub name: String,
    pub description: String,
    /// 是否常驻加载（类似 VikingBot always_load）
    pub always_load: bool,
    /// 依赖要求
    pub requires: SkillRequirements,
    /// 自定义元数据
    pub metadata: HashMap<String, String>,
    /// 技能内容（Markdown）
    pub content: String,
}

pub struct SkillRequirements {
    /// 需要的二进制文件
    pub binaries: Vec<String>,
    /// 需要的环境变量
    pub env_vars: Vec<String>,
}

impl SkillsSource {
    /// 从 skills/ 目录加载所有技能
    pub async fn load_skills(&self) -> Vec<SkillManifest> {
        let mut skills = Vec::new();
        
        for entry in fs::read_dir(&self.skills_dir).await? {
            let path = entry?.path();
            if path.extension() == Some("md") {
                let manifest = self.parse_skill(&path).await?;
                
                // 验证依赖
                if self.validate_requirements(&manifest.requires) {
                    skills.push(manifest);
                } else {
                    log::warn!("Skill {} requirements not met", manifest.name);
                }
            }
        }
        
        skills
    }
    
    /// 解析技能文件 frontmatter
    async fn parse_skill(&self, path: &Path) -> Result<SkillManifest> {
        let content = fs::read_to_string(path).await?;
        
        // 解析 YAML frontmatter
        let (frontmatter, body) = parse_frontmatter(&content)?;
        
        Ok(SkillManifest {
            name: frontmatter["name"].as_str().unwrap_or("").to_string(),
            description: frontmatter["description"].as_str().unwrap_or("").to_string(),
            always_load: frontmatter["always_load"].as_bool().unwrap_or(false),
            requires: SkillRequirements {
                binaries: frontmatter["requires"]["binaries"]
                    .as_array()
                    .map(|arr| arr.iter().map(|v| v.as_str().unwrap_or("").to_string()).collect())
                    .unwrap_or_default(),
                env_vars: frontmatter["requires"]["env_vars"]
                    .as_array()
                    .map(|arr| arr.iter().map(|v| v.as_str().unwrap_or("").to_string()).collect())
                    .unwrap_or_default(),
            },
            metadata: frontmatter["metadata"]
                .as_object()
                .map(|obj| obj.iter().map(|(k, v)| (k.clone(), v.as_str().unwrap_or("").to_string())).collect())
                .unwrap_or_default(),
            content: body.to_string(),
        })
    }
    
    /// 验证依赖要求
    fn validate_requirements(&self, requires: &SkillRequirements) -> bool {
        // 检查二进制文件
        for binary in &requires.binaries {
            if !which::which(binary).is_ok() {
                return false;
            }
        }
        
        // 检查环境变量
        for env_var in &requires.env_vars {
            if std::env::var(env_var).is_err() {
                return false;
            }
        }
        
        true
    }
}

impl ContextSource for SkillsSource {
    fn layer(&self) -> ContextLayer { ContextLayer::Dynamic }
    fn priority(&self) -> i32 { 40 }
    
    async fn inject(&self, _ctx: &BuildContext) -> Vec<Message> {
        let skills = self.load_skills().await;
        
        // 分离常驻技能和可发现技能
        let (resident, discoverable): (Vec<_>, Vec<_>) = skills
            .into_iter()
            .partition(|s| s.always_load);
        
        let mut messages = Vec::new();
        
        // 常驻技能：完整内联
        if !resident.is_empty() {
            let resident_content = resident.iter()
                .map(|s| format!("## {}\n{}", s.name, s.content))
                .collect::<Vec<_>>()
                .join("\n\n");
            
            messages.push(Message::system(format!(
                "## 常驻技能\n{}",
                resident_content
            )));
        }
        
        // 可发现技能：仅摘要
        if !discoverable.is_empty() {
            let summary = discoverable.iter()
                .map(|s| format!("- {}: {}", s.name, s.description))
                .collect::<Vec<_>>()
                .join("\n");
            
            messages.push(Message::system(format!(
                "## 可用技能（按需调用）\n{}",
                summary
            )));
        }
        
        messages
    }
}
```

**技能文件示例**（`skills/github.md`）：

```markdown
---
name: "GitHub 集成"
description: "与 GitHub API 交互，管理仓库、Issue、PR"
always_load: false
requires:
  binaries: ["gh"]
  env_vars: ["GITHUB_TOKEN"]
metadata:
  category: "dev"
  author: "user"
---

# GitHub 集成

## 能力

- 创建/查看 Issue
- 创建/合并 PR
- 查看仓库状态

## 使用示例

用户："帮我查看最近的 Issue"
→ 使用 `github issue list` 工具
```

**设计理由**（借鉴 VikingBot）：

- `always_load`：常驻技能完整内联，可发现技能仅摘要
- `requires`：依赖验证，避免运行时失败
- `metadata`：扩展信息，支持分类和过滤

## 第 3 层：用户消息

### 运行时上下文注入

```rust
pub struct UserLayerBuilder;

impl UserLayerBuilder {
    pub fn build(&self, inbound: &InboundMessage) -> Message {
        let runtime_context = format!(
            "[当前时间：{}，平台：{}，语言：{}]",
            chrono::Local::now().format("%Y-%m-%d %H:%M %A %z"),
            std::env::consts::OS,
            "zh-CN"
        );
        
        let content = if inbound.media.is_empty() {
            format!("{}\n\n{}", runtime_context, inbound.content)
        } else {
            // 多模态消息
            format!("{}\n\n{}\n\n[附件：{}个媒体文件]",
                runtime_context,
                inbound.content,
                inbound.media.len()
            )
        };
        
        Message::user(content)
    }
}
```

**设计理由**：

- 运行时数据（时间/平台）不放入系统提示词，避免污染缓存
- 合并到用户消息，保持系统提示词稳定

## 完整构建流程

```rust
impl AgentLoop {
    async fn build_messages(&self, inbound: &InboundMessage) -> Vec<Message> {
        let mut messages = Vec::new();
        
        // 第 1 层：核心稳定（从缓存获取）
        let core_message = self.core_cache.get_or_build(&self.core_builder);
        messages.push(core_message);
        
        // 第 2 层：动态上下文（按优先级排序）
        let ctx = BuildContext {
            session: &self.session,
            inbound,
            history: vec![], // 历史单独处理
        };
        
        let mut dynamic_sources: Vec<_> = self.dynamic_sources
            .iter()
            .filter(|s| s.layer() == ContextLayer::Dynamic)
            .collect();
        dynamic_sources.sort_by_key(|s| s.priority());
        
        for source in dynamic_sources {
            let msgs = source.inject(&ctx).await;
            messages.extend(msgs);
        }
        
        // 历史消息（已压缩）
        let history = self.session_manager
            .compressed_history(&self.session)
            .await;
        messages.extend(history);
        
        // 第 3 层：用户消息
        messages.push(self.user_layer.build(inbound));
        
        messages
    }
}
```

## 记忆升华机制

```rust
impl MemoryStore {
    /// 提议将记忆升华为知识
    pub async fn propose_crystallization(&self, memory_id: &str) -> Result<KnowledgeDraft> {
        let memory = self.get(memory_id).await?;
        
        // 只有高 importance 记忆才能升华
        if memory.importance < 0.8 {
            return Err("Importance too low".into());
        }
        
        // 生成知识草稿
        let draft = KnowledgeDraft {
            title: format!("关于 {}", memory.key),
            content: format!("观察到：{}\n\n建议整理为知识笔记。", memory.content),
            source_memory: memory_id.to_string(),
        };
        
        Ok(draft)
    }
}

/// 知识草稿，需人类确认
pub struct KnowledgeDraft {
    pub title: String,
    pub content: String,
    pub source_memory: String,
}

/// 人类确认后写入 vault/knowledge/
impl KnowledgeService {
    pub async fn create_from_draft(&self, draft: KnowledgeDraft) -> Result<()> {
        let path = format!("vault/knowledge/{}.md", sanitize_filename(&draft.title));
        let content = format!(
            "# {}\n\n{}\n\n---\n\n来源记忆：{}",
            draft.title,
            draft.content,
            draft.source_memory
        );
        
        fs::write(&path, content).await?;
        Ok(())
    }
}
```

## 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 三层分离 | Core / Dynamic / User | 平衡缓存稳定性与动态上下文 |
| Memory 位置 | 第 2 层（Dynamic） | Agent 私有，每次请求召回 |
| Knowledge 位置 | 第 2 层（Dynamic） | 人机共有，RAG 检索 |
| 运行时数据 | 第 3 层（User） | 避免污染系统提示词缓存 |
| 升华机制 | 记忆 → 草稿 → 人类确认 → 知识 | 体现"人机共有" |
| 缓存策略 | 仅第 1 层缓存 | 第 2 层动态变化，无法缓存 |

## 与 nanobot 的差异

| 维度 | nanobot | MindClaw（本设计） |
|------|---------|-------------------|
| 层级 | 两层（系统提示词 + 用户消息） | 三层（Core + Dynamic + User） |
| 缓存稳定性 | 完整系统提示词缓存 | 仅 Core 层缓存 |
| Memory | 两层（工作+长期） | 单层，第 2 层动态注入 |
| Knowledge | 无明确概念 | 一等概念，第 2 层注入 |
| 核心命题 | 无 | 记忆是 Agent 的，知识是共同的 |
| 升华机制 | 无 | 记忆 → 知识草稿 → 人类确认 |
