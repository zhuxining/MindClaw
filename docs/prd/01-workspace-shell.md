# 工作台壳层与全局交互

→ 架构关联：[08-desktop-frontend.md](../architecture/08-desktop-frontend.md)
→ 父文档：[00-overview.md](00-overview.md)

## 背景与目标

**背景**：MindClaw 的桌面端需要一个稳定工作台，让用户在 Daily、Inbox、Vault、Private、Agent、Memory 等工作域之间切换，同时保持当前内容、上下文面板和 Agent 协作入口连贯。

**目标**：定义 Ribbon（工作域活动栏）、左侧面板、中央多 Tab 内容区、右侧上下文面板、状态栏与全局打开逻辑。

## 功能描述

### US-01 显示工作台基础布局

作为用户，我希望打开 MindClaw 后看到固定工作台布局，以便在同一窗口内完成记录、浏览、编辑和 Agent 协作。

**验收标准**：

- [ ] 应用启动后显示五个区域：Ribbon、左侧面板、中央内容区、右侧上下文面板、状态栏。
- [ ] Ribbon 固定在窗口最左侧，宽度为 36px。
- [ ] 左侧面板默认宽度为 260px，可折叠，可拖拽调整宽度。
- [ ] 右侧上下文面板默认宽度为 300px，可折叠，可拖拽调整宽度。
- [ ] 中央内容区在左右面板宽度变化后占据剩余空间。
- [ ] 窗口宽度小于 900px 时，右侧上下文面板自动折叠。

**优先级**：P0

---

### US-02 通过 Ribbon 切换工作域

作为用户，我希望点击 Ribbon 入口切换工作域，以便快速进入当前任务所需的操作空间。

**验收标准**：

Given 用户处于任意工作域
When 用户点击 Ribbon 中的 Daily、Inbox、Vault、Private、Agent、Memory、Settings 任一入口
Then 被点击入口显示选中态，左侧面板切换为对应工作域内容，中央内容区打开该工作域默认 Tab

Given 用户已在某个工作域打开内容
When 用户切换到另一个工作域后再切回原工作域
Then 原工作域保留最后打开的 Tab 和左侧面板状态

- [ ] Ribbon 第一版只显示 Daily、Inbox、Vault、Private、Agent、Memory、Settings。
- [ ] 当前工作域入口使用选中态标识。
- [ ] Ribbon 入口 hover 时显示入口名称。
- [ ] Tasks、Graph、Skills、MCP、Session、Cron 不显示为 MVP 主入口。

**优先级**：P0

---

### US-03 管理左侧面板

作为用户，我希望左侧面板随工作域切换显示不同导航内容，以便减少无关信息干扰。

**验收标准**：

Given 用户切换工作域
When 左侧面板加载完成
Then 面板标题、工具按钮和内容列表与当前工作域一致

Given 左侧面板已展开
When 用户点击折叠按钮
Then 左侧面板收起，仅保留 Ribbon 和中央内容区

Given 左侧面板已折叠
When 用户点击展开按钮或再次点击当前 Ribbon 入口
Then 左侧面板恢复到折叠前宽度

- [ ] 左侧面板宽度调整后持久化，应用重启后恢复。
- [ ] 每个工作域保留独立的筛选、滚动和展开状态。
- [ ] 左侧面板空状态显示当前工作域可执行的最小操作。

**优先级**：P0

---

### US-04 管理中央多 Tab 内容区

作为用户，我希望中央内容区以 Tab 承载笔记、资源、Agent 会话和设置页，以便并行处理多个工作对象。

**验收标准**：

Given 用户从左侧面板打开一个对象
When 中央内容区已存在同一对象 Tab
Then 系统激活已存在 Tab，不创建重复 Tab

Given 用户从左侧面板打开一个新对象
When 中央内容区不存在对应 Tab
Then 系统在当前 Tab 右侧创建新 Tab 并激活

Given 用户关闭当前 Tab
When 仍有其他 Tab 存在
Then 系统激活关闭 Tab 左侧最近一个 Tab

- [ ] Tab 标题显示对象名称。
- [ ] 未保存内容的 Tab 显示未保存标识。
- [ ] 关闭含未保存内容的 Tab 前触发保存或确认流程。
- [ ] 应用重启后恢复最后激活的工作域和最后打开对象。

**优先级**：P0

---

### US-05 管理右侧上下文面板

作为用户，我希望右侧面板显示当前内容的上下文信息，以便在编辑和协作时查看大纲、Frontmatter、关联内容和 Agent 建议。

**验收标准**：

Given 中央内容区激活 Markdown 笔记
When 右侧面板展开
Then 右侧面板显示大纲、Frontmatter、关联内容三个区域

Given 中央内容区激活 Agent Session
When 右侧面板展开
Then 右侧面板显示引用上下文、执行状态、生成草稿三个区域

Given 中央内容区激活 Private 内容
When 右侧面板展开
Then 右侧面板不显示发送给 Agent、生成记忆、写入知识类操作

- [ ] 右侧面板可折叠，折叠状态持久化。
- [ ] 右侧面板区域标题固定，内容区可滚动。
- [ ] 当前内容不支持上下文区域时显示空状态，不显示无效操作。

**优先级**：P0

---

### US-06 使用全局快捷动作

作为用户，我希望在工作台顶部或左侧面板中执行常用动作，以便快速创建内容或进入当天工作。

**验收标准**：

- [ ] Open Today 打开或创建当日 Daily Note。
- [ ] New Note 在 Vault 中创建新 Markdown 笔记。
- [ ] New Session 创建新的 Agent Session Tab。
- [ ] Add Link 将链接保存到 Inbox 待处理列表。
- [ ] 全局动作在 Private 工作域中不提供“发送给 Agent”类入口。

**优先级**：P1

## 交互矩阵

| Ribbon 入口 | 左侧面板 | 中央默认内容 | 右侧上下文面板 |
|-------------|----------|--------------|----------------|
| Daily | 日期列表、当日 checklist、回顾入口 | 今日 Daily Note | 大纲、Frontmatter、关联内容 |
| Inbox | 待处理列表、来源类型筛选、审核状态筛选 | Inbox 列表或选中条目 | 处理动作、来源引用、目标去向 |
| Vault | 文件树、标签、搜索 | 最近打开笔记或 Vault 首页 | 大纲、Frontmatter、关联内容 |
| Private | Private 文件树、搜索 | 最近打开私密笔记 | 大纲、Frontmatter，不显示 Agent 操作 |
| Agent | 会话列表、上下文对象 | 最近 Agent Session | 引用上下文、执行状态、草稿 |
| Memory | 记忆分类、确认状态筛选、回顾队列入口 | Agent Memory 列表 | 证据、来源、知识引用、候选动作 |
| Settings | 设置分组 | 工作区设置页 | 帮助说明或空状态 |

## 范围界定

**In Scope**：

- Ribbon MVP 入口与选中态。
- 左侧面板、中央 Tab、右侧上下文面板、状态栏的基础交互。
- 工作域切换后的状态保留。
- 面板折叠、展开、拖拽宽度与持久化。
- MVP 全局快捷动作。

**Out of Scope**：

- 自定义 Ribbon 入口排序：MVP 入口固定，避免设置项影响核心路径验证。
- Graph、Skills、MCP、Cron 工作域：这些能力不进入 MVP 主导航。
- 多窗口与拖出 Tab：当前桌面端以单窗口工作台为交付边界。
- 插件化面板系统：第一版只定义固定面板区域，插件扩展需独立架构和权限设计。

## 非功能需求

- 工作域切换后左侧面板首屏内容在 300ms 内完成显示。
- 面板折叠或展开动效时长为 150ms。
- 最小可用窗口尺寸为 900px × 600px。
