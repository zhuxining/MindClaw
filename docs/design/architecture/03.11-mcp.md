# MCP 集成

> 基于 rmcp 的 Model Context Protocol 集成

## 概述

MCP（Model Context Protocol）集成允许 MindClaw 连接任何符合 MCP 标准的服务器，扩展 Agent 的能力。MCP 工具会被自动发现，封装为原生 MindClaw 工具，与内置工具一起提供给 Agent 使用。

**设计原则**：

- **延迟连接**：首次需要时建立连接
- **透明封装**：MCP 工具与原生工具无差别
- **命名空间隔离**：使用 `mcp__tool` 格式避免冲突
- **生命周期管理**：优雅连接、错误恢复、干净关闭

## rmcp 传输支持

| 传输方式 | 支持状态 | 说明 |
|---------|---------|------|
| **stdio** | ✅ 完整支持 | `TokioChildProcess` - 子进程通信 |
| **streamable-http** | ✅ 完整支持 | `StreamableHttpClientTransport` - 单端点，自动 SSE |
| SSE（旧版双端点） | ❌ 不支持 | 已被 streamable-http 替代（MCP 2025-03-26+）|
| WebSocket | ✅ 支持 | `ws.rs`（较少使用）|

**MCP 协议演进**：

- **2024-11-05**: stdio + HTTP+SSE（双端点）
- **2025-03-26**: 引入 streamable-http（单端点，内置 SSE）
- **2025-11-25**: streamable-http 成为推荐方案，HTTP+SSE 进入兼容模式

## 配置

### MCPServerConfig

```rust
/// MCP 服务器配置
#[derive(Debug, Clone, Deserialize)]
pub struct MCPServerConfig {
    /// 服务器名称（用于标识）
    pub name: String,
    /// 传输类型
    #[serde(default)]
    pub transport: MCPTransport,
    /// stdio: 命令
    pub command: Option<String>,
    /// stdio: 参数
    #[serde(default)]
    pub args: Vec<String>,
    /// stdio: 环境变量
    #[serde(default)]
    pub env: HashMap<String, String>,
    /// streamable-http: URL
    pub url: Option<String>,
    /// streamable-http: 认证 Token
    pub auth_token: Option<String>,
    /// streamable-http: 自定义请求头
    #[serde(default)]
    pub headers: HashMap<String, String>,
    /// 工具调用超时
    #[serde(default = "default_timeout")]
    pub timeout: Duration,
    /// 工具过滤（空表示全部）
    #[serde(default)]
    pub enabled_tools: Vec<String>,
}

#[derive(Debug, Clone, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum MCPTransport {
    Stdio,
    StreamableHttp,
}

impl Default for MCPTransport {
    fn default() -> Self {
        MCPTransport::Stdio
    }
}

fn default_timeout() -> Duration {
    Duration::from_secs(30)
}
```

## MCP Manager

### 核心职责

- **延迟连接**：首次调用时建立所有连接
- **工具发现**：从每个服务器获取工具列表
- **工具注册**：将 MCP 工具封装并注册到 ToolRegistry
- **生命周期**：优雅关闭所有连接

### 实现

```rust
use rmcp::{ServiceExt, transport::{TokioChildProcess, StreamableHttpClientTransport}};
use rmcp::transport::streamable_http_client::StreamableHttpClientTransportConfig;
use rmcp::model::CallToolRequestParams;
use tokio::process::Command;
use std::sync::Arc;
use tokio::sync::RwLock;

/// MCP 管理器
pub struct MCPManager {
    configs: Vec<MCPServerConfig>,
    /// 已连接的客户端
    clients: RwLock<HashMap<String, Arc<MCPClient>>>,
    /// 连接状态
    connected: AtomicBool,
}

/// MCP 客户端包装
pub struct MCPClient {
    inner: rmcp::Client,
    config: MCPServerConfig,
}

impl MCPManager {
    pub fn new(configs: Vec<MCPServerConfig>) -> Self {
        Self {
            configs,
            clients: RwLock::new(HashMap::new()),
            connected: AtomicBool::new(false),
        }
    }
    
    /// 确保已连接（延迟连接）
    pub async fn ensure_connected(&self) -> Result<()> {
        // 已连接则直接返回
        if self.connected.load(Ordering::SeqCst) {
            return Ok(());
        }
        
        // 连接所有服务器
        for config in &self.configs {
            match self.connect_server(config).await {
                Ok(client) => {
                    let mut clients = self.clients.write().await;
                    clients.insert(config.name.clone(), Arc::new(client));
                }
                Err(e) => {
                    log::error!("Failed to connect MCP server '{}': {}", config.name, e);
                    // 继续连接其他服务器
                }
            }
        }
        
        self.connected.store(true, Ordering::SeqCst);
        Ok(())
    }
    
    /// 连接单个服务器
    async fn connect_server(&self, config: &MCPServerConfig) -> Result<MCPClient> {
        let client = match config.transport {
            MCPTransport::Stdio => {
                self.connect_stdio(config).await?
            }
            MCPTransport::StreamableHttp => {
                self.connect_streamable_http(config).await?
            }
        };
        
        Ok(MCPClient {
            inner: client,
            config: config.clone(),
        })
    }
    
    /// stdio 连接
    async fn connect_stdio(&self, config: &MCPServerConfig) -> Result<rmcp::Client> {
        let cmd = config.command.as_ref()
            .ok_or("Command required for stdio transport")?;
        
        let mut command = Command::new(cmd);
        command.args(&config.args);
        command.envs(&config.env);
        
        let transport = TokioChildProcess::new(command)?;
        let client = ().serve(transport).await?;
        
        Ok(client)
    }
    
    /// streamable-http 连接
    async fn connect_streamable_http(&self, config: &MCPServerConfig) -> Result<rmcp::Client> {
        let url = config.url.as_ref()
            .ok_or("URL required for streamable-http transport")?;
        
        let mut transport_config = StreamableHttpClientTransportConfig::with_uri(url);
        
        // 配置认证
        if let Some(token) = &config.auth_token {
            transport_config = transport_config.auth_header(token);
        }
        
        // 配置自定义请求头
        for (key, value) in &config.headers {
            transport_config = transport_config.header(key, value);
        }
        
        // 启用会话过期自动重新初始化
        transport_config = transport_config.reinit_on_expired_session(true);
        
        let transport = StreamableHttpClientTransport::with_config(transport_config);
        let client = ().serve(transport).await?;
        
        Ok(client)
    }
    
    /// 获取所有 MCP 工具
    pub async fn get_tools(&self) -> Vec<MCPTool> {
        let mut tools = Vec::new();
        let clients = self.clients.read().await;
        
        for (server_name, client) in clients.iter() {
            match client.inner.list_all_tools().await {
                Ok(mcp_tools) => {
                    for mcp_tool in mcp_tools {
                        // 工具过滤
                        if !self.is_tool_enabled(&client.config, &mcp_tool.name) {
                            continue;
                        }
                        
                        let tool = MCPTool::new(
                            server_name.clone(),
                            mcp_tool,
                            client.clone(),
                        );
                        tools.push(tool);
                    }
                }
                Err(e) => {
                    log::error!("Failed to list tools from '{}': {}", server_name, e);
                }
            }
        }
        
        tools
    }
    
    /// 检查工具是否启用
    fn is_tool_enabled(&self, config: &MCPServerConfig, tool_name: &str) -> bool {
        if config.enabled_tools.is_empty() {
            return true;
        }
        
        let prefixed_name = format!("mcp__{}", tool_name);
        config.enabled_tools.contains(&tool_name.to_string())
            || config.enabled_tools.contains(&prefixed_name)
    }
    
    /// 关闭所有连接
    pub async fn close_all(&self) {
        let clients = self.clients.read().await;
        for (name, client) in clients.iter() {
            if let Err(e) = client.inner.cancel().await {
                log::warn!("Error closing MCP server '{}': {}", name, e);
            }
        }
        self.connected.store(false, Ordering::SeqCst);
    }
}
```

## MCP Tool 封装

### MCPTool

```rust
/// MCP 工具包装
pub struct MCPTool {
    /// 服务器名称
    server_name: String,
    /// MCP 原始名称
    original_name: String,
    /// 封装后的名称（mcp__tool）
    prefixed_name: String,
    /// 描述
    description: String,
    /// 参数 Schema
    schema: serde_json::Value,
    /// MCP 客户端
    client: Arc<MCPClient>,
    /// 超时
    timeout: Duration,
}

impl MCPTool {
    pub fn new(server_name: String, mcp_tool: rmcp::model::Tool, client: Arc<MCPClient>) -> Self {
        let original_name = mcp_tool.name.clone();
        let prefixed_name = format!("mcp__{}", original_name);
        
        Self {
            server_name,
            original_name,
            prefixed_name,
            description: mcp_tool.description.unwrap_or_default(),
            schema: normalize_schema(mcp_tool.input_schema),
            client,
            timeout: client.config.timeout,
        }
    }
}

#[async_trait]
impl Tool for MCPTool {
    fn name(&self) -> &str {
        &self.prefixed_name
    }
    
    fn description(&self) -> &str {
        &self.description
    }
    
    fn parameters_schema(&self) -> serde_json::Value {
        self.schema.clone()
    }
    
    fn timeout(&self) -> Option<Duration> {
        Some(self.timeout)
    }
    
    async fn execute(&self, params: serde_json::Value) -> Result<String, String> {
        let request = CallToolRequestParams {
            meta: None,
            name: self.original_name.clone(),
            arguments: Some(params),
        };
        
        // 带超时执行
        let result = match tokio::time::timeout(
            self.timeout,
            self.client.inner.call_tool(request)
        ).await {
            Ok(Ok(result)) => result,
            Ok(Err(e)) => {
                return Err(format!("MCP error: {}", e));
            }
            Err(_) => {
                return Err(format!("Timeout after {:?}", self.timeout));
            }
        };
        
        // 转换结果为字符串
        format_mcp_result(result)
    }
}

/// 格式化 MCP 结果为字符串
fn format_mcp_result(result: rmcp::model::CallToolResult) -> Result<String, String> {
    let mut outputs = Vec::new();
    
    for content in result.content {
        match content {
            rmcp::model::ToolResponseContent::Text(text) => {
                outputs.push(text.text);
            }
            rmcp::model::ToolResponseContent::Image(image) => {
                // 图像转换为 markdown
                outputs.push(format!(
                    "![{}](data:{};base64,{})",
                    image.annotations.as_ref()
                        .and_then(|a| a.description.clone())
                        .unwrap_or_default(),
                    image.mime_type,
                    image.data
                ));
            }
            _ => {
                // 其他类型转为 JSON
                outputs.push(serde_json::to_string(&content)
                    .unwrap_or_default());
            }
        }
    }
    
    if outputs.is_empty() {
        Ok("(no output)".to_string())
    } else {
        Ok(outputs.join("\n\n"))
    }
}

}
```

## 与 ToolRegistry 集成

```rust
impl ToolRegistry {
    /// 从 MCP Manager 注册工具
    pub async fn register_mcp_tools(&mut self, mcp_manager: &MCPManager) -> Result<()> {
        // 确保已连接
        mcp_manager.ensure_connected().await?;
        
        // 获取所有 MCP 工具
        let tools = mcp_manager.get_tools().await;
        
        // 注册到 registry
        for tool in tools {
            log::info!("Registering MCP tool: {}", tool.name());
            self.register(Box::new(tool));
        }
        
        Ok(())
    }
}
```

```rust
impl AgentLoop {
    pub async fn run(&mut self) -> Result<()> {
        // 延迟连接 MCP（首次需要时）
        if let Some(mcp) = &self.mcp_manager {
            if let Err(e) = mcp.ensure_connected().await {
                log::error!("MCP connection failed: {}", e);
                // 继续运行，只是没有 MCP 工具
            }
        }
        
        // ... 主循环
    }
    
    pub async fn stop(&mut self) {
        // 关闭 MCP 连接
        if let Some(mcp) = &self.mcp_manager {
            mcp.close_all().await;
        }
        
        // ... 其他清理
    }
}
```

## 错误处理

```rust
/// MCP 错误类型
pub enum MCPError {
    /// 连接失败
    ConnectionError(String),
    /// 工具调用失败
    ToolError(String),
    /// 超时
    Timeout(Duration),
    /// 协议错误
    ProtocolError(String),
}

impl From<MCPError> for ToolResult {
    fn from(err: MCPError) -> Self {
        match err {
            MCPError::ConnectionError(msg) => {
                ToolResult::error("mcp", "", format!("Connection failed: {}", msg))
            }
            MCPError::ToolError(msg) => {
                ToolResult::error("mcp", "", format!("Tool error: {}. Please fix and retry.", msg))
            }
            MCPError::Timeout(d) => {
                ToolResult::error("mcp", "", format!("Timeout after {:?}. Please try again.", d))
            }
            MCPError::ProtocolError(msg) => {
                ToolResult::error("mcp", "", format!("Protocol error: {}", msg))
            }
        }
    }
}
```

## 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| SDK | rmcp | 官方 Rust SDK，功能完整 |
| 传输方式 | stdio + streamable-http | 覆盖所有推荐场景，streamable-http 内置 SSE |
| 连接时机 | 延迟连接 | 避免启动时阻塞，按需连接 |
| 工具命名 | `mcp__tool` | 统一 MCP 工具命名空间 |
| 工具过滤 | enabled_tools | 细粒度控制可用工具 |
| 超时 | 可配置 | 适应不同工具执行时间 |
| 错误处理 | 优雅降级 | 单个 MCP 失败不影响其他 |

## 传输选择指南

| 场景 | 推荐传输 | 配置示例 |
|------|---------|---------|
| 本地工具 | **stdio** | `command: npx`, `args: [...]` |
| Web 部署 | **streamable-http** | `url: "http://..."` |
| 需要 SSE 推送 | **streamable-http** | 自动支持，无需额外配置 |
| 旧版兼容 | **streamable-http** | 自动降级兼容旧版 SSE |
