# 反思回顾与演化记录

→ 架构关联：[03.11-observability.md](../architecture/03.11-observability.md)
→ 父文档：[00-overview.md](00-overview.md)

## 背景与目标

**背景**：Agent 的能力变化不能只停留在会话上下文或不可见记忆中。异步观察需要通过反思回顾被判断，关键变化需要形成演化记录，稳定经验需要沉淀为经验教训或共有知识。

**目标**：定义异步观察、轻量回顾、周期回顾、演化记录、经验教训和知识沉淀的用户可见流程。

## 功能描述

### US-01 查看异步观察

作为用户，我希望查看 Agent 捕捉到的观察假设，以便决定哪些信号值得保留。

**验收标准**：

Given 系统存在待审阅观察
When 用户打开回顾视图
Then 页面列出观察内容、来源对象、产生时间和置信状态

Given 用户点击某条观察
When 详情加载完成
Then 右侧面板显示该观察关联的 Session、Daily、Inbox 或 Vault 来源

- [ ] 观察以假设状态显示。
- [ ] 观察不能直接升级为共有知识。
- [ ] Private 来源不出现在观察列表。

**优先级**：P0

---

### US-02 执行轻量回顾

作为用户，我希望在一次 Agent 协作或当日记录结束后做轻量回顾，以便确认本次产生的记忆和经验。

**验收标准**：

Given Agent Session 存在用户纠正、失败、确认或草稿
When 用户点击 Review Session
Then 回顾视图显示记忆更新建议、经验候选和知识草稿入口

Given Daily 存在新增记录、checklist 变化或 Inbox 整理结果
When 用户点击 Review Today
Then 回顾视图显示当日变化摘要和待确认观察

Given 用户确认一条记忆更新建议
When 操作完成
Then 该建议进入 Agent Memory，并生成演化记录候选

**优先级**：P1

---

### US-03 执行周期回顾

作为用户，我希望按周期回顾重复出现的模式，以便把多次案例提炼为经验教训。

**验收标准**：

Given 系统存在多条相似观察、案例或用户修正
When 用户打开周期回顾
Then 页面按主题列出可合并的模式候选

Given 用户选择一个模式候选
When 详情加载完成
Then 页面显示支撑该候选的案例列表和反例列表

Given 用户确认模式候选
When 操作完成
Then 系统生成经验教训候选，并关联支撑案例

**优先级**：P2

---

### US-04 生成演化记录

作为用户，我希望看到 Agent 记忆或策略为什么发生变化，以便审计 Agent 演化过程。

**验收标准**：

Given 用户确认、修正、删除、降权或升级一条记忆
When 操作完成
Then 系统生成演化记录，记录变化前内容、变化后内容、触发原因和来源

Given 用户查看演化记录
When 详情加载完成
Then 页面显示关联记忆、关联 Session 或关联知识笔记

Given 演化记录来源缺失
When 用户查看详情
Then 页面显示无来源状态，并禁止升级为经验教训

- [ ] 演化记录不可直接编辑正文。
- [ ] 用户可为演化记录补充备注。
- [ ] 演化记录可按时间、来源、变化类型筛选。

**优先级**：P0

---

### US-05 沉淀经验教训和共有知识

作为用户，我希望把确认后的演化结果沉淀为经验教训或共有知识，以便 Agent 和人类后续复用。

**验收标准**：

Given 演化记录已确认
When 用户点击 Create Lesson
Then 系统生成经验教训候选，包含适用场景、处理方法、反例和来源记录

Given 经验教训候选已打开
When 用户点击 Save as Knowledge
Then 中央内容区打开 Vault 知识草稿，包含标题、`tags`、`overview` 和正文

Given 知识草稿保存到 Vault
When 保存完成
Then 原演化记录显示已沉淀为共有知识，并链接到对应笔记

**优先级**：P1

## 范围界定

**In Scope**：

- 异步观察的审阅入口。
- Session 回顾与 Daily 回顾。
- 周期回顾的模式候选展示。
- 演化记录生成、查看、筛选、备注。
- 经验教训候选与共有知识草稿生成。

**Out of Scope**：

- 全自动写入共有知识：共有知识需要用户确认，避免错误经验扩散。
- 对 Private 内容做观察和回顾：该行为违反 Private 隔离边界。
- 复杂评分体系：MVP 只展示置信状态，不引入多维分数维护。
- 团队协作审批流：当前产品定位为个人桌面工作站。

## 非功能需求

- 回顾视图首屏在 1 秒内显示。
- 单条演化记录详情在 500ms 内显示。
- 生成知识草稿后，草稿 Tab 在 300ms 内激活。
